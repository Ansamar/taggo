## Novità
- **Svuota elenco** (⇧⌘⌫): nuovo pulsante nella barra in alto e voce nel menu **File**. Toglie tutti i brani dalla finestra senza toccare i file sul disco. Se ci sono modifiche non salvate, Taggo chiede conferma.
- **⌫** toglie dall'elenco solo i brani selezionati.

## Download
- **Taggo-0.1.1.dmg**: apri il file e trascina Taggo in Applicazioni. Se hai già la 0.1.0, sostituiscila.
- **Taggo-0.1.1.zip**: la stessa app in formato compresso

Per macOS 14 Sonoma o successivo, Mac Apple Silicon e Intel.

**Primo avvio:** l'app non è firmata da uno sviluppatore registrato Apple, quindi macOS la blocca.
Su macOS 15 e successivi: apri Taggo, chiudi l'avviso, poi vai in **Impostazioni di Sistema → Privacy e sicurezza → Apri comunque**.
Su macOS 14: tasto destro su Taggo → **Apri**.

Guida: [Come usare Taggo](https://github.com/Ansamar/taggo/blob/main/HOW_TO_USE.md). È anche nell'app, nel menu **Aiuto**.

Verifica dei file scaricati: `SHA256SUMS.txt`.
