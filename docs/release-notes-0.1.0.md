Prima versione di **Taggo**, editor di tag audio per macOS.

## Download
- **Taggo-0.1.0.dmg**: apri il file e trascina Taggo in Applicazioni
- **Taggo-0.1.0.zip**: la stessa app in formato compresso

Per macOS 14 Sonoma o successivo, Mac Apple Silicon e Intel.

**Primo avvio:** l'app non è firmata da uno sviluppatore registrato Apple, quindi macOS la blocca.
Su macOS 15 e successivi: apri Taggo, chiudi l'avviso, poi vai in **Impostazioni di Sistema → Privacy e sicurezza → Apri comunque**.
Su macOS 14: tasto destro su Taggo → **Apri**.

## Cosa fa
- Modifica di uno o più file insieme, con copertine
- Tag → Nome file e Nome file → Tag con segnaposto (`%artist% - %title%`)
- Numerazione automatica e **divisione di un album in dischi**
- Maiuscole/minuscole, cerca e sostituisci (anche espressioni regolari)
- Ricerca su **MusicBrainz** con copertine, apertura in **MusicBrainz Picard**, ricerca su Discogs, AllMusic, Wikipedia e altri siti
- Formati: MP3, M4A/AAC/ALAC, FLAC, OGG, Opus, WAV, AIFF, APE, WavPack, WMA e altri

Guida completa: [Come usare Taggo](https://github.com/Ansamar/taggo/blob/main/HOW_TO_USE.md). È anche nell'app, nel menu **Aiuto**.

Fai una copia di prova dei tuoi file prima del primo utilizzo.

Verifica dei file scaricati: `SHA256SUMS.txt`.
